# بوت التحميل — الإصدار 5 — Render مجاني: الصغير في تيليجرام والكبير برابط

كود مفتوح المصدر برخصة MIT. إعداد Render يحتاج **BOT_TOKEN وOWNER_ID فقط**. لا يحتاج حساب مطور تيليجرام أو API ID أو API Hash أو خادم Bot API محلي.

## السلوك المطلوب

- المستخدم يرسل الرابط ويتعرف البوت على المنصة تلقائيًا، بدون أزرار تحميل.
- المستخدم الجديد يرسل طلب استخدام للمالك، والمالك وحده يوافق أو يرفض بأزرار خاصة به.
- الموافقة مرة لكل مستخدم وتبقى محفوظة بعد إعادة التشغيل عند استخدام القرص الدائم.
- المستخدم الموافق عليه يرسل عدة روابط وتبدأ بالتوازي؛ لا يوجد طابور تنزيل أو حصة يومية أو حد طلب واحد.
- حتى **49,000,000 بايت** للملف: يرسل داخل تيليجرام؛ MP4 كفيديو وMP3 كصوت والبقية كمستندات.
- ملف يوتيوب الأكبر من ذلك وحتى **300,000,000 بايت**: رابط مباشر لتنزيل الملف كاملًا من المتصفح.
- ما يزيد عن 300 ميجا ليوتيوب لا يُرسل. بقية المنصات تبقى عند حد 49 ميجا.
- الرابط صالح ساعة افتراضيًا. يحذف الملف تلقائيًا بعد انتهاء الصلاحية، بفحص كل دقيقة. تنزيل بدأ قبل انتهاء الصلاحية يمكن أن يكتمل، ثم يحذف الملف.
- الروابط طويلة وعشوائية وغير مفهرسة بقائمة ملفات. **من يملك الرابط يستطيع تنزيل الملف خلال صلاحيته**؛ الرابط ليس تسجيل دخول مرتبطًا بحساب تيليجرام. سحب صلاحية صاحبه يمنع فتحه ويوقف استمرار تدفقه عند فحص الصلاحية التالي.
- يدعم الرابط HTTP Range لاستكمال التنزيل. الرابط المنتهي أو المجهول يعطي 404.

الحدود هنا MB عشرية. لا يوجد ضغط تلقائي لتقليل الحجم. يفحص البوت الحجم النهائي بعد دمج الفيديو والصوت أو التحويل. إزالة طابور التطبيق لا تزيل حدود موارد السيرفر أو معدل إرسال تيليجرام.

## أوامر الاستخدام

```text
https://رابط_المقطع
صوت https://رابط_المقطع
بحث اسم المقطع
/audio https://رابط_المقطع
/search اسم المقطع
/cancel
```

البحث في يوتيوب يعرض خمس نتائج بروابط نصية، والمستخدم يرسل الرابط المطلوب. `/cancel` يلغي كل تنزيلاته الجارية، لكن رفعًا بدأ بالفعل لتيليجرام قد يكتمل.

للمالك فقط:

```text
/requests
/allow 123456789
/deny 123456789
```

الأول يعرض الطلبات المعلقة، الثاني يسمح، والثالث يرفض أو يسحب الصلاحية. إذا أرسل المستخدم رابطًا أثناء انتظار الموافقة، يبدأ أول طلب محفوظ تلقائيًا بعد الموافقة. إذا تعذر إرسال إشعار للمالك يبقى الطلب محفوظًا.

## المنصات والحدود الواقعية

- يوتيوب وشورتس: فيديو حتى جودة 1080 حسب المتاح، أو MP3. حد الملف 300 ميجا.
- إنستغرام: ريلز وفيديو وصور ومنشورات وروابط ستوري متاحة للحساب. الستوري الخاص أو تسجيل الدخول قد يحتاج cookies لحساب مخول.
- تويتر / X: صور وفيديو المنشورات.
- تيك توك: فيديو وصور بحسب ما يتيحه المصدر؛ النسخة بدون العلامة غير مضمونة ولا توجد أداة لمسح علامة محروقة داخل الفيديو.
- حالات واتساب: أرسل الحالة المحفوظة صورة/فيديو/مستندًا؛ لا يسحب البوت حالات جهات الاتصال.
- لا بحث عام في إنستغرام أو تيك توك، ولا تنزيل حسابات كاملة أو قوائم تشغيل أو بث حي غير منتهٍ.
- حظر عناوين السيرفر وتغييرات المواقع والمحتوى الخاص قد يمنع التنزيل. لا يوجد ضمان أن كل رابط يعمل. استخدم المحتوى الذي تملك حق تنزيله.

## النشر على Render خطوة بخطوة

**الإعداد المرفق مجاني**: Web Service بخطة `free` بدون قرص دائم. الموافقات والكاش والروابط المؤقتة تفقد عند إعادة التشغيل أو النشر أو النوم. سيحتاج الأصدقاء موافقة جديدة؛ المالك يظل معروفًا من OWNER_ID. لحفظ الموافقات دائمًا تحتاج تخزينًا خارجيًا أو قرصًا مدفوعًا.

1. فك ضغط أحدث نسخة، وافتح مجلد `social_bot`.
2. ارفع **محتويات المجلد** إلى جذر مستودع GitHub، بحيث يظهر `render.yaml` و`Dockerfile` و`bot.py` و`downloads.py` مباشرة في الجذر. لا ترفع ZIP بدل الملفات.
3. لا ترفع `.env` أو مجلد `data` أو cookies. ملف `.env.example` نموذج فارغ مسموح رفعه.
4. في Render اختر New → Blueprint، واربط المستودع.
5. أدخل:

| المتغير | القيمة |
|---|---|
| BOT_TOKEN | توكن بوتك من BotFather |
| OWNER_ID | آيديك الشخصي الرقمي في تيليجرام، وليس آيدي البوت |

6. باقي القيم يضبطها `render.yaml`. رابط التنزيل يعتمد على `RENDER_EXTERNAL_URL` الذي يوفره Render تلقائيًا.
7. تأكد أن الخطة Free ولا يوجد قرص مدفوع، ثم ابدأ النشر. Docker يثبت FFmpeg وDeno وPython والمكتبات. لا تحتاج أوامر build أو start مخصصة.
8. افتح بوتك أنت أولًا واضغط Start حتى يستطيع إشعارك بطلبات الأصدقاء.
9. جرّب من حساب صديق: طلب الموافقة، الموافقة، رابط صغير ثم فيديو يوتيوب أكبر من 49 وأقل من 300 ميجا.

إذا تنشر يدويًا: اختر Web Service وDocker وخطة Free بدون قرص، واضبط `DATA_DIR=/tmp/social-bot-data` والمتغيرين الأساسيين، واجعل Health Check Path هو `/healthz`. البوت يستخدم polling لاستقبال رسائل تيليجرام، وخادم HTTP لتنزيل الملفات. لا تحتاج Webhook أو سر Webhook في هذا الإصدار.

إذا رفعت النسخة السابقة: استبدل ملفات المشروع بهذه النسخة، وأضف `downloads.py`، واحذف `launcher.py` القديم. حدّث إعدادات Render ليستخدم `python bot.py` من Dockerfile الجديد. احذف متغيرات `TELEGRAM_API_ID` و`TELEGRAM_API_HASH` و`RUN_LOCAL_BOT_API` و`MIGRATE_CLOUD_ONCE` و`BOT_API_URL` و`WEBHOOK_SECRET` و`WEBHOOK_URL` لأنها لم تعد مستخدمة. يحتفظ `store.py` بالموافقات القديمة إذا كان نفس القرص متصلًا.

### مراقبة الموقع مثل بوت الصيد

في موقع المراقبة الذي تستخدمه أضف HTTP monitor لرابط `https://YOUR-SERVICE.onrender.com/healthz`، واستبدل YOUR-SERVICE باسم خدمتك الحقيقي. اجعل الفحص كل 5 دقائق بطريقة GET وانتظر استجابة 200. المسار `/` ليس مسار المراقبة. هذا فحص HTTP خارجي؛ لا تحتاج تعديل كود البوت.

Render ينام بعد 15 دقيقة بلا طلبات واردة؛ المراقبة الدورية قد تبقي الخدمة نشطة لكنها لا تضمن تشغيلًا متواصلًا أو تمنع إعادة تشغيلها. حساب 750 ساعة مجاني لكل مساحة عمل شهريًا تتشاركه الخدمات؛ بوتان يعملان باستمرار يستهلكانه خلال نحو 15.6 يوم. المراقبة لا تتجاوز هذه الحصة. كذلك نقل الملفات الكبيرة يستهلك حصة الشبكة، وقد يوقف Render خدمة مجانية كثيرة الحركة.

بعد إعادة تشغيل الخدمة أعد الموافقات من طلبات المستخدمين أو `/allow USER_ID`، وأعد إرسال روابط المقاطع لإصدار روابط تنزيل جديدة. لا تشغّل أكثر من نسخة للبوت نفسه. إذا كانت لديك خدمة مدفوعة قائمة فلا يكفي رفع YAML وحده لضمان تغيير الفوترة؛ راجع خطة الخدمة وأزل القرص فقط بعد حفظ أي بيانات تحتاجها.

## الإعدادات الاختيارية

| المتغير | الافتراضي / وظيفته |
|---|---|
| PUBLIC_BASE_URL | فارغ على Render؛ يستعمل رابط Render التلقائي. على استضافة أخرى ضع أصل الرابط العام HTTPS بدون مسار، مثل https://bot.example.com |
| LINK_TTL_SECONDS | 3600 ثانية؛ لا تقل عن 60 |
| DATA_DIR | ./data محليًا، /tmp/social-bot-data على Render المجاني |
| PORT | 10000، أو القيمة التي توفرها الاستضافة |
| VIDEO_HEIGHT | 1080 |
| COOKIES_FILE | مسار اختياري لملف Netscape cookies لحسابك المخول |
| DOWNLOAD_TIMEOUT | صفر: لا مهلة إجمالية؛ مهلة الشبكة وإعادة المحاولات ما زالت موجودة |
| JOB_DISK_LIMIT_MB | صفر: لا حد مساحة لكل طلب؛ موارد القرص الفعلية تبقى محدودة |

ملفات كبيرة متعددة تتقاسم مساحة الاستضافة المؤقتة المحدودة. لا يوجد قرص دائم 5GB في الإعداد المجاني. راقب المساحة واستهلاك نقل البيانات؛ روابط التنزيل تستهلك شبكة Render. إذا امتلأ القرص يفشل الطلب برسالة للمستخدم، وتبقى الملفات غير المنتهية حتى انتهاء مدتها أو زيادة مساحة القرص.

ملفات تيليجرام الصغيرة تحفظ بمعرّفات file_id لسرعة إعادة الإرسال. الملفات الكبيرة لا تخزن في ذاكرة file_id، ويصدر لها رابط جديد عند تنزيلها مجددًا. الموافقات وبيانات الروابط محفوظة في SQLite. إعادة التشغيل توقف التنزيلات الجارية، لكنها تحفظ الروابط الجاهزة حتى انتهاء وقتها إذا بقي القرص الدائم. ينظف التشغيل التالي مؤقتات العمل المتروكة من النسخة السابقة. في إعداد Free المرفق لا يوجد قرص دائم وتفقد تلك البيانات بعد إعادة التشغيل.

## تشغيل محلي

ثبّت Python 3.12+ وFFmpeg وDeno في PATH. انسخ `.env.example` إلى `.env` وأدخل التوكن وآيديك. افتح `run.bat`، أو:

```bash
pip install -r requirements.txt
python bot.py
```

الروابط المحلية الافتراضية تستعمل `http://localhost:10000`، وتعمل على نفس الكمبيوتر فقط. للوصول من هاتف أو صديق، انشر على Render أو اضبط عنوانًا عامًا قابلًا للوصول في `PUBLIC_BASE_URL`. لا يكفي تغيير النص إلى عنوان غير مربوط بالخادم.

Docker محليًا:

```bash
docker compose up -d --build
```

المنفذ 10000 مكشوف في compose والقرص المسمى يحفظ البيانات.
